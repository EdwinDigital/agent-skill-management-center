# Web 应用设计标准

本目录沉淀自当前 ACR 智能洞察工作站的前端设计语言，用于后续新建 Web 应用时复用一致的视觉、布局和组件规范。模板资源完全独立，不被当前应用引用；复制到新项目后再按业务场景调整。

## 设计原则

- 中文优先：默认中文界面，英文作为可选语言。
- 工作台优先：首屏直接呈现可操作的业务界面，不做营销式 Landing Page。
- 数据密度适中：卡片、表格、图表要适合扫描、对比和反复使用。
- 克制但有识别度：使用清晰的 Microsoft/Azure 蓝作为主色，少量高亮色表达状态。
- 主题一致：Dark / Light 共用同一套语义变量，不在组件里散落硬编码颜色。
- 隐私友好：涉及客户和财务数字的应用应预留隐私模式入口。

## 颜色语义

| Token | 用途 | Light | Dark |
|---|---|---|---|
| `--bg` | 页面背景 | `#eef3fa` | `#0e1320` |
| `--panel` | 卡片背景 | `#ffffff` | `#171e2b` |
| `--panel-strong` | 强调面板/按钮 | `#f7faff` | `#202a3a` |
| `--line` | 边框/分割线 | `#e3eaf5` | `#28313f` |
| `--text` | 主文字 | `#172033` | `#eef2f8` |
| `--muted` | 次级文字 | `#667085` | `#9aa6b6` |
| `--accent` | 主操作/图线 | `#0078d4` | `#0078d4` |
| `--growth` | 增长 | `#ff174f` | `#ff174f` |
| `--decline` | 下跌 | `#16a34a` | `#00ffd5` |

增长和下跌颜色语义必须保持一致：增长使用荧光红，深色模式下跌使用荧光青绿，浅色模式下跌使用普通绿色。

## 布局规范

### 应用骨架

- 顶部固定 Header：高度 `54px`，包含应用标识、标题、账户、主题与语言切换。
- 左侧数据管理栏：默认宽度 `340px`，折叠宽度 `42px`。
- 右侧智能分析栏：默认宽度 `clamp(300px, 24vw, 390px)`，折叠宽度 `42px`。
- 主内容区：`minmax(0, 1fr)`，所有网格子项必须设置 `min-width: 0`，防止文本撑破布局。

### 栅格

- KPI 区：桌面端 6 列，卡片高度约 `112px`。
- 分析区：12 列栅格，趋势/结构/排行各占 4 列。
- 详情表：全宽卡片，表格横向滚动而不是挤压字段。

### 折叠侧栏

- 左右折叠侧栏均显示底部图标按钮。
- 图标上方使用竖排文字提示，例如“数据管理”“使用 Copilot 洞察”。
- 折叠栏宽度固定 `42px`，正文元素隐藏但不改变主内容布局节奏。

## 字体与文字

- 字体族：`Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", "Microsoft YaHei", sans-serif`。
- 不使用负 letter-spacing；默认 `letter-spacing: 0`。
- 卡片内标题不使用 Hero 级字号，避免信息密集界面显得笨重。
- 长文本必须处理溢出：表格可省略，排行条目使用右侧渐变遮罩。

## 组件规范

### Header

- App 标识为 30px 方形图标，8px 圆角。
- 主标题 14-18px，副标题/品牌英文使用 9px uppercase。
- 右侧按钮统一使用 `.icon-button`。

### Hero Summary

- Hero 是业务摘要，不是宣传 Banner。
- 背景使用 `--hero` 渐变，文字保持白色。
- 客户名旁可放隐私模式眼睛按钮。
- 统计数字走格式化函数，不直接拼接裸数字。

### KPI Card

- 每张 KPI 左侧 4px accent 竖条。
- 数字 24px / 900 weight。
- 重要正负状态通过 `.up` / `.down` / `.flat` 显示。

### Bar Ranking

- 名称列和条形列必须隔离，名称不可覆盖条形图。
- 长名称使用 CSS mask 渐变淡出，而不是溢出到图表上。
- 完整名称放在 `title` 属性中。

### Trend Chart

- SVG viewBox 应使用真实容器尺寸，避免文字被拉伸。
- Y 轴范围按数据动态计算，但默认不显示左侧刻度和中间网格线。
- X 轴标签允许两行显示，例如 `Jun` / `2025`，`Nov` / `预估`。

### Table

- 表格数字列右对齐，使用 tabular nums。
- 详情页分页数字也需要支持隐私模式。
- 表格容器可横向滚动，禁止用缩小字体牺牲可读性。

### Privacy Mode

- 隐私模式只影响显示层，不能改变底层数据、排序、聚合、图表几何和判断逻辑。
- 金额、百分比、TPID、行数、序号、日期数字等显示为 `***`。
- 按钮使用眼睛/隐藏眼睛图标，并通过 `aria-pressed` 暴露状态。

## 可访问性

- 图标按钮必须有 `aria-label` 和 `title`。
- 折叠按钮维护 `aria-expanded`。
- 隐私按钮维护 `aria-pressed`。
- 颜色表达状态时，也要保留符号或文本信息，例如 `+/-`。

## 文件说明

- `templates/app-shell.html`：完整页面骨架模板。
- `assets/design-tokens.css`：主题变量、基础 reset、应用骨架布局。
- `assets/components.css`：Header、侧栏、Hero、KPI、排行、表格、隐私按钮等组件样式。
- `assets/template.js`：主题切换、侧栏折叠、隐私模式和格式化函数示例。

## 使用方式

1. 复制 `templates/app-shell.html` 到新项目入口。
2. 引入 `assets/design-tokens.css` 和 `assets/components.css`。
3. 按业务替换 `main` 区域卡片内容。
4. 保留 CSS 变量命名和组件 class，新增业务组件时优先复用 token。
5. 如果项目包含敏感客户或财务数据，启用 `template.js` 中的隐私模式格式化函数。
