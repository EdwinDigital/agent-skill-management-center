# Support

## Start Here

1. Read the [documentation index](docs/README.md).
2. Check [troubleshooting](docs/troubleshooting.md) or [故障排查](docs/troubleshooting-CN.md).
3. Search existing [Issues](https://github.com/EdwinDigital/agent-skill-management-center/issues).
4. Collect the app version, operating system/architecture, exact steps, and sanitized errors.

## Where to Ask

- Reproducible defects: use the [bug report form](https://github.com/EdwinDigital/agent-skill-management-center/issues/new?template=bug_report.yml).
- Product or workflow proposals: use the [feature request form](https://github.com/EdwinDigital/agent-skill-management-center/issues/new?template=feature_request.yml).
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md) and report privately.

Please do not post OAuth tokens, private Skill content, customer data, full home-directory paths, or database files. This project is maintained on a best-effort basis; response times are not guaranteed.
